# Sports Court Booking System

Безупречная система бронирования спортивных площадок с разделением ролей (Спортсмен / Администратор).

## Технологический стек
- **Backend:** Python, FastAPI, SQLAlchemy, Pydantic, JWT Auth
- **Database:** SQLite / PostgreSQL
- **Frontend:** JavaScript, Tailwind CSS, Axios
